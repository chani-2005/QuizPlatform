# Multi-User Async Quiz Platform 🏆

A sophisticated Java-based web application designed for real-time, asynchronous competitive quizzes. The platform allows creators to manage quizzes via Excel imports and provides a dynamic experience for multiple participants to compete simultaneously.

## 🌟 Key Features

### For Administrators (Quiz Creators)
- **Identity Management:** Secure login via Google Authentication or advanced Face Recognition[cite: 3].
- **Dynamic Content Loading:** Quizzes are generated by uploading Excel files containing questions, four possible answers, and designated point values[cite: 3].
- **Quiz Controls:** Set specific start and end times for each session[cite: 3].
- **Management Dashboard:** View all created quizzes, update schedules, or append/overwrite question banks[cite: 3].

### For Participants (Players)
- **Easy Join:** Participants join via a unique Quiz ID during the active time window[cite: 3].
- **Custom Profiles:** Players set their own display names and profile pictures[cite: 3].
- **Anti-Cheat Logic:** Questions and their respective answers are shuffled randomly for every player[cite: 3].
- **Live Leaderboard:** A real-time display at the top of the screen shows all participants, their profile pictures, and current scores[cite: 3].
- **Automated Winner Declaration:** At the conclusion of the time limit, the system identifies and displays the winner based on points and response speed[cite: 3].

## 🛠️ Architecture & Design

The project follows a clean **Model-Repository-Service** architecture to ensure scalability and maintainability:

### Data Models
- **Quiz:** Stores metadata including ID, title, creator email, timing, and current winner[cite: 3].
- **Question:** Contains the question text, four options, difficulty level, and response time limits[cite: 3].
- **Player:** Tracks the participant's unique session ID, score, and profile details[cite: 3].

### Core Logic
- **Asynchronous Processing:** The platform operates asynchronously to handle concurrent player updates without lag[cite: 3].
- **Service Layer:** 
  - **Quiz Service:** Manages CRUD operations and creator-specific queries[cite: 3].
  - **Player Service:** Handles real-time answer validation, scoring, and leaderboard updates[cite: 3].
- **Persistence:** All quiz and question data is stored in a structured database[cite: 3].

## 🚀 Technical Requirements
- **Language:** Java
- **Database:** SQL-based (for Quiz and Question storage)
- **External APIs:** Google Auth, Face Recognition API[cite: 3]
